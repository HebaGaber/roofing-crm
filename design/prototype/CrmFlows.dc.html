Roofing CRM · flows

CRM · not Task A

A map-based roofing lead CRM for a sales rep in Travis County, TX. It reads only the data CountyLens publishes (read-only, Run 3) and adds GPS and pin-drop radius search, leads and an agent that can create leads. Every Crm board opens with the Map view (CRM preview) switch on. Mobile first: the field flow is the main one. Sample data.
