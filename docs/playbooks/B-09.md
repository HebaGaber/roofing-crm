## Draft acceptance criteria (put these in the story file, then edit)

As a **roofing sales rep**, I want **to ask for opportunities in plain English**, so that **I find leads faster than with filters**.

1. Given 'show me open roofing permits older than five years within five miles of Pflugerville', when asked, then real records return with citations.
2. Given results, when shown, then they appear as numbered pins on the map and can become leads.
3. Given assumptions, when shown as chips and one is edited, then the query re-runs.
4. Given low retrieval confidence or no results, when answering, then the agent says so and suggests a change.
5. Given a question outside the data, when asked, then the agent declines instead of guessing.
