## Draft acceptance criteria (put these in the story file, then edit)

As a **roofing sales rep**, I want **the CRM to work on any device and be observable**, so that **it is production quality**.

1. Given 390, 768 and 1440 widths, when every screen is tested, then smeargle's responsive tests pass.
2. Given the backend, when used, then Powertools metrics (searches, leads created, agent latency) appear on a CloudWatch dashboard.
3. Given a failing sync batch, when it fails, then the DLQ alarm fires.
4. Given prefers-reduced-motion, when set, then animations are off and gestures fall back to buttons.
