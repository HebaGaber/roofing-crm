## Draft acceptance criteria (put these in the story file, then edit)

As a **roofing sales rep**, I want **open roofing permits ranked by how long they have been open**, so that **I find stalled jobs worth a call**.

1. Given the permit layer, when on, then open roofing permits in the radius show sorted by open duration, longest first.
2. Given a permit open more than 5 years, when shown, then it has the Open > 5 yrs badge.
3. Given a filter open at least N years, when set, then only those permits show.
4. Given each result, when shown, then the why-is-this-a-lead chips explain the signal.
