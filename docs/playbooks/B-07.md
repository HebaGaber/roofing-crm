## Draft acceptance criteria (put these in the story file, then edit)

As a **roofing sales rep**, I want **to turn matches into leads and track them**, so that **opportunities are not lost**.

1. Given a property, when Create lead is used from the drawer, list, agent or a right swipe, then a lead is saved with a signals snapshot and source CIDs.
2. Given a lead, when its status changes or a note is added, then the history records who and when.
3. Given a reload, when the leads page opens, then all changes persist.
4. Given a property that already has a lead, when Create lead is used again, then no duplicate is created and the existing lead opens.
5. Given a swipe-created lead, when Undo is tapped, then the lead is removed.
