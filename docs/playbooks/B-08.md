## Draft acceptance criteria (put these in the story file, then edit)

As a **roofing sales rep**, I want **a list of candidates I can filter and share**, so that **I can plan my day**.

1. Given combined roof-age, permit status, open-duration and radius filters, when applied, then the list and map match.
2. Given filters, when applied, then they appear in the URL and the same URL restores them.
3. Given many results, when listed, then pagination shows 1–50 of N with real counts.
4. Given filters with no results, when applied, then the empty state suggests which filter to relax.
